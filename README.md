# 🎨 Color Generator

A lightweight web app that generates random gradient backgrounds, previews them instantly, and lets you copy the CSS with one click.

Built with **HTML, CSS, and JavaScript**, with no frameworks and no dependencies.

## ✨ Features

- 🎲 Generate random gradient backgrounds with a single click
- 👀 Instant live preview of the gradient
- 💻 View the matching CSS code
- 📋 Copy the CSS to your clipboard in one click
- ⚡ Lightweight, with everything in a single `index.html` file

| Technology | Purpose                         |

| HTML5      | Page structure                  |
| CSS3       | Styling and gradient rendering  |

## 🚀 Getting Started

No installation or build step needed.

1. **Clone the repository**
   ```bash
   git clone https://github.com/student-BPSMV/Color-Generator.git
   ```
2. **Open the project folder**
   ```bash
   cd Color-Generator
   ```
3. **Open `index.html`** in your browser (double-click it, or right-click → *Open with* → your browser).

---

## 📖 How to Use

1. Click the **Generate** button to create a new random gradient.
2. Watch the background update instantly.
3. Check the CSS code displayed on the page.
4. Click **Copy** and paste the code straight into your own project.
